# Assets Folder

This folder contains all static assets for EasyResume AI.

## Folder Structure

```
assets/
├── logos/          # Company and product logos
├── icons/           # UI icons and small graphics
├── images/          # General images and photos
└── illustrations/    # Custom illustrations and graphics
```

## Usage

### Logos
- Store company logos, product logos, and brand assets
- Use SVG format when possible for scalability
- Include different sizes if needed (small, medium, large)

### Icons
- UI icons for buttons, navigation, and interface elements
- Prefer SVG or PNG with transparent background
- Organize by category (social, navigation, actions, etc.)

### Images
- Photos, banners, and general graphics
- Use optimized formats (WebP, JPG, PNG)
- Include responsive versions if needed

### Illustrations
- Custom graphics and illustrations
- SVG format recommended for scalability
- Organize by theme or section

## File Naming

Use descriptive names:
- `logo-primary.svg`
- `icon-twitter.svg`
- `hero-banner.webp`
- `illustration-resume.svg`

## Optimization

- Compress images for web
- Use appropriate formats (SVG for icons, WebP for photos)
- Consider responsive images for different screen sizes

## Access in Code

```tsx
// Example usage in components
import logo from '/assets/logos/logo-primary.svg'
import icon from '/assets/icons/icon-twitter.svg'
```
